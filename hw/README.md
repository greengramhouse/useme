# ฟอร์มบันทึกน้ำหนัก–ส่วนสูงนักเรียน

หน้าเว็บนิ่ง (HTML + JS + Tailwind CDN ไม่ต้องใช้ Node) ให้ครูประจำชั้นกรอกน้ำหนัก/ส่วนสูงของห้องตัวเอง
· ล็อกอินด้วยบัญชีระบบทะเบียนนักเรียนเดิม · รายชื่อดึงจาก API เดิม · เก็บข้อมูลลง Google Sheet
· ประเมินภาวะโภชนาการรายคนตามเกณฑ์กรมอนามัย 2564 พร้อมกราฟ · แท็บติดตามว่าห้องไหนส่งแล้วกี่ %

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอทั้งหมด |
| `config.js` | **ที่อยู่ API และ Apps Script — ไฟล์เดียวที่ต้องแก้** |
| `api.js` | ⭐ ต้นแบบ: ล็อกอิน + ดึงข้อมูลจากระบบทะเบียน (ยกไปใช้งานอื่นได้) |
| `sheet.js` | ⭐ ต้นแบบ: คุยกับ Apps Script โดยไม่ติด CORS |
| `growth-data.js` | ตารางเกณฑ์กรมอนามัย + ค่า WHO (ข้อมูลล้วน) |
| `growth.js` | คำนวณ BMI / ภาวะโภชนาการ / สูงดีสมส่วน |
| `chart.js` | กราฟรายคน (SVG) |
| `app.js` | ควบคุมหน้าจอ |
| `code.gs` | หลังบ้าน — คัดลอกไปวางใน Apps Script (ไม่ได้ใช้บนหน้าเว็บ) |

## ติดตั้ง (ทำครั้งเดียว)

### 1. Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ (ตั้งชื่ออะไรก็ได้) — **อย่าแชร์ชีตนี้ให้ครู** ครูไม่ต้องเข้าชีตเลย
2. เมนู **ส่วนขยาย ▸ Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทิ้ง แล้ววางเนื้อหาไฟล์ `code.gs` ทั้งหมดลงไป → กด 💾
4. ตรวจบรรทัด `const API_URL = '...'` ให้ตรงกับ API ของระบบทะเบียน
5. เลือกฟังก์ชัน **`setup`** ในแถบด้านบน แล้วกด **▶ Run**
   → Google จะขออนุญาต (แก้ชีต + ต่ออินเทอร์เน็ต) ให้กดอนุญาต
   → ชีต `Settings` กับ `Records` จะถูกสร้างให้

### 2. Deploy เป็น Web App

1. ปุ่ม **Deploy ▸ New deployment** → ⚙️ เลือก **Web app**
2. ตั้งค่า
   - **Execute as: Me** (รันในนามเจ้าของชีต)
   - **Who has access: Anyone** ← สำคัญ ถ้าเลือกอย่างอื่นหน้าเว็บจะเรียกไม่ได้
3. กด Deploy → คัดลอก **Web app URL** (ลงท้าย `/exec`)
4. เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"data":{"service":"weight-height-form",...}}`
5. วาง URL ลงใน `config.js` ช่อง `GAS_URL`

> ความปลอดภัย: "Anyone" แปลว่าใครก็ยิงมาได้ แต่ `code.gs` ตรวจ token ของระบบทะเบียนทุกครั้ง
> ว่าเป็นใคร และเป็นครูประจำชั้นห้องนั้นจริงไหม — คนที่ไม่มีบัญชีอ่าน/เขียนอะไรไม่ได้

### 3. วางหน้าเว็บบน GitHub Pages

1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
   (`code.gs` จะอัปไปด้วยก็ได้ ไม่มีความลับ แต่ไม่จำเป็น)
2. **Settings ▸ Pages ▸ Source: Deploy from a branch ▸ main / (root)** → Save
3. รอ 1–2 นาที จะได้ URL เช่น `https://greengramhouse.github.io/weight-height/`

### 4. อนุญาตโดเมนใหม่ที่ API ของระบบทะเบียน

ไม่ทำข้อนี้ = ล็อกอินไม่ได้ ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้"

1. Vercel ▸ project `thaingam-api-bun` ▸ Settings ▸ Environment Variables ▸ `CORS_ORIGINS`
2. **เติมต่อท้าย** (คั่นด้วย comma ไม่มีเว้นวรรค) — ใส่แค่โดเมน ไม่มี path ไม่มี `/` ท้าย:
   ```
   https://thaingam-student.vercel.app,https://greengramhouse.github.io
   ```
   ⚠️ ค่าเดิมถูกซ่อนไว้อ่านกลับไม่ได้ ต้องพิมพ์ทั้งก้อนใหม่ อย่าลืมโดเมนเดิม
3. **Deployments ▸ ⋯ ▸ Redeploy** (ตั้ง env แล้วไม่ redeploy = ยังไม่มีผล)
4. ตรวจ (ต้องเห็นบรรทัด `access-control-allow-origin: https://greengramhouse.github.io`):
   ```
   curl -si -X OPTIONS https://thaingam-api-bun.vercel.app/me \
     -H "Origin: https://greengramhouse.github.io" \
     -H "Access-Control-Request-Method: GET" | grep -i access-control-allow-origin
   ```

### 5. ผูกบัญชีครูกับข้อมูลครู

ครูต้อง (1) มีบัญชีล็อกอินในระบบทะเบียน และ (2) บัญชีถูกผูกกับข้อมูลครูแล้ว
— แอดมินผูกได้ที่ **หน้ารายละเอียดครู** ในระบบทะเบียน
ครูที่ยังไม่ผูกจะล็อกอินได้ แต่ขึ้นข้อความ "ยังไม่ได้ผูกกับข้อมูลครู" แทนตาราง

## ใช้งานประจำ

- **เปลี่ยนรอบ** (เช่นขึ้นภาคเรียนใหม่): แก้ช่อง **B2 ของชีต `Settings`** เช่น `2/2569`
  → ฟอร์มว่างใหม่ ข้อมูลรอบเก่ายังอยู่ในชีต `Records`
- **ดูข้อมูลดิบ / ส่งรายงาน**: ชีต `Records` มีผลประเมินเก็บไว้แล้ว (กรอง/นับ/ดาวน์โหลด Excel ได้เลย)
- **แก้ `code.gs`** ภายหลัง: วางโค้ดใหม่ ▸ Deploy ▸ **Manage deployments** ▸ ✏️ ▸ Version: **New version** ▸ Deploy
  (URL เดิม ไม่ต้องแก้ `config.js`) · ถ้ากด New deployment จะได้ URL ใหม่ ต้องแก้ `config.js`
- **ทดสอบในเครื่องกับ API ตอนพัฒนา**: เปลี่ยน `API_URL` ใน `config.js` เป็น `http://localhost:5000`
  แล้วเปิดหน้าผ่านเซิร์ฟเวอร์ (เช่น `npx serve`) ไม่ใช่ดับเบิลคลิกไฟล์

## เกณฑ์ที่ใช้ประเมิน

| อายุ | ส่วนสูงตามเกณฑ์อายุ | น้ำหนักตามเกณฑ์ส่วนสูง |
|---|---|---|
| 6–19 ปี | ตารางที่ 7 คู่มือกรมอนามัย 2564 | ตารางที่ 8 คู่มือกรมอนามัย 2564 |
| ต่ำกว่า 6 ปี (อนุบาล) | WHO 2006 / 2007 | WHO 2006 (2–5 ปี) |

- ที่มา: คู่มือการใช้เกณฑ์อ้างอิงการเจริญเติบโตของเด็กอายุ 6–19 ปี สำนักโภชนาการ กรมอนามัย (ส.ค. 2564)
  https://nutrition2.anamai.moph.go.th/th/book/201949
- **สูงดีสมส่วน** = ส่วนสูงระดับ "สูงตามเกณฑ์" ขึ้นไป **และ** น้ำหนักระดับ "สมส่วน"
- อายุนับเป็นเดือนเต็ม ณ วันที่กรอกค่า · ส่วนสูงปัดเป็นจำนวนเต็ม ซม. ก่อนเปิดตารางน้ำหนัก (เหมือนเปิดคู่มือ)
- BMI แสดงเป็นตัวเลขอย่างเดียว — กรมอนามัยประเมินเด็กด้วยน้ำหนักตามส่วนสูง
- ⚠️ ตารางในคู่มือเป็นรูปภาพ ค่าใน `growth-data.js` ถอดทีละหน้าแล้วตรวจความต่อเนื่องด้วยสคริปต์
  ถ้าพบค่าไม่ตรงคู่มือ แก้ใน `growth-data.js` ได้ตรงๆ (แถวละ 1 เดือน / 1 ซม.)

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ล็อกอินแล้วขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | โดเมนยังไม่อยู่ใน `CORS_ORIGINS` หรือยังไม่ redeploy API (ข้อ 4) · หรือเปิดไฟล์จากเครื่องตรงๆ |
| แถบแดง "เชื่อมต่อ Google Sheet ไม่ได้" | `GAS_URL` ว่าง/ผิด · หรือ Deploy ไม่ได้เลือก Anyone |
| "Google Sheet ตอบกลับผิดรูปแบบ" | Who has access ไม่ใช่ Anyone (ได้หน้าล็อกอิน Google กลับมาแทน) |
| แก้ `code.gs` แล้วไม่เห็นผล | ยังไม่ได้ออก New version (ดู "ใช้งานประจำ") |
| ครูเห็นข้อความ "ยังไม่ได้ผูก" | แอดมินผูกบัญชีที่หน้ารายละเอียดครู แล้วให้ครูล็อกอินใหม่ |
| ถอดครูออกจากห้องแล้วยังบันทึกได้ | Apps Script จำสิทธิ์ไว้ 10 นาที (`CACHE_SECONDS`) รอสักครู่ |

## ใช้เป็นต้นแบบงานอื่น

งานใหม่ที่อยากใช้ "บัญชีครู + รายชื่อนักเรียน" ของระบบทะเบียน:

1. คัดลอก `api.js` (ล็อกอิน/รายชื่อ) และ `sheet.js` (ถ้าเก็บลง Google Sheet) ไปทั้งไฟล์
2. ฝั่ง Apps Script คัดลอกส่วน **"ต้นแบบ: ตรวจ token ของระบบทะเบียน"** ใน `code.gs`
   (`verifyCaller_`, `classroomAccess_`, `apiGet_`, `apiGetAll_`) — แล้วเขียน action ของงานใหม่เอง
3. เพิ่มโดเมนของงานใหม่ใน `CORS_ORIGINS` (ถ้าอยู่คนละโดเมน — ถ้าอยู่ `xxx.github.io` เดียวกันไม่ต้องเพิ่มซ้ำ)

ตัวอย่างการเรียกอยู่ท้ายไฟล์ `api.js`
