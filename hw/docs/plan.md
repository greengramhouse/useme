## ภาพรวมการไหลของข้อมูล

```
 เบราว์เซอร์ (GitHub Pages)                 ระบบเดิม (thaingam-api-bun.vercel.app)
 ┌──────────────────────────┐  ① sign-in   ┌───────────────────────────────┐
 │ index.html + *.js         │────────────►│ POST /api/auth/sign-in/email  │
 │                           │◄── token ───│                               │
 │ token เก็บใน sessionStorage│  ② อ่านรายชื่อ│ GET /me · /teachers · /classrooms│
 │                           │────────────►│ GET /students?classroomId=…   │
 └────────────┬──────────────┘  Bearer     └───────────────▲───────────────┘
              │ ③ บันทึก/อ่านค่า (ส่ง token ไปด้วย)              │ ④ ตรวจ token ซ้ำ
              ▼  POST text/plain                              │  (UrlFetchApp)
 ┌───────────────────────────────────────────────────────────┴─┐
 │ Apps Script Web App (code.gs) + Google Sheet                 │
 │  Settings: รอบที่กำลังเก็บ   Records: น้ำหนัก/ส่วนสูง/ผลประเมิน      │
 └──────────────────────────────────────────────────────────────┘
```

**จุดสำคัญด้านความปลอดภัย (ข้อ ④):** Apps Script **ไม่เชื่อสิ่งที่หน้าเว็บบอก** ว่าเป็นใคร/ห้องไหน —
ทุกครั้งที่อ่านหรือเขียน จะเอา token ที่ส่งมาไปถาม API เองว่าเป็นใคร เป็นครูประจำชั้นห้องนั้นจริงไหม
และนักเรียนที่ส่งมาอยู่ในห้องนั้นจริงไหม (จำผลไว้ 10 นาที) · ไม่มีบัญชีกลางหรือรหัสผ่านเก็บใน Apps Script เลย

### เกณฑ์ภาวะโภชนาการ

| อายุ | ส่วนสูงตามเกณฑ์อายุ | น้ำหนักตามเกณฑ์ส่วนสูง |
|---|---|---|
| **6–19 ปี** | ตารางที่ 7 กรมอนามัย 2564 (รายเดือน 72–228 เดือน) | ตารางที่ 8 กรมอนามัย 2564 (ราย ซม. 90–185 ชาย / 90–175 หญิง) |
| **ต่ำกว่า 6 ปี** (อนุบาล) | WHO 2006 (0–60 ด.) + WHO 2007 (61–71 ด.) คำนวณ z จาก LMS | WHO 2006 weight-for-height 65–120 ซม. |

- ระดับ: ส่วนสูง = เตี้ย · ค่อนข้างเตี้ย · สูงตามเกณฑ์ · ค่อนข้างสูง · สูง (ตัดที่ ±1.5 / ±2 SD)
  น้ำหนัก = ผอม · ค่อนข้างผอม · สมส่วน · ท้วม · เริ่มอ้วน · อ้วน (ตัดที่ ±1.5 / ±2 / +3 SD)
- **สูงดีสมส่วน** = สูงตามเกณฑ์ขึ้นไป **และ** สมส่วน (นิยามจาก SOP ตัวชี้วัด KPI 3.5 ของสำนักโภชนาการ)
- ตารางกรมอนามัยเป็นราย ซม. → **ปัดส่วนสูงเป็นจำนวนเต็มก่อนเปิดตาราง** (เหมือนครูเปิดตารางกระดาษ)
- BMI = กก. ÷ ม.² แสดงเป็นตัวเลขอย่างเดียว — กรมอนามัยประเมินเด็กด้วยน้ำหนักตามส่วนสูง ไม่ใช่ BMI
- ค่าตารางกรมอนามัย**ถอดจากภาพในคู่มือ** (PDF ไม่มีข้อความให้คัดลอก ยกเว้น 2 หน้า) แล้วตรวจด้วยสคริปต์ว่า
  ทุกคอลัมน์เพิ่มขึ้นต่อเนื่อง ไม่มีค่ากระโดด — ผ่านทั้ง 157 + 96 แถว

### ไม่ทำ (ไม่ได้ขอ)

## ข้อความระหว่างหน้าเว็บกับ Apps Script

`POST` body = JSON string · `Content-Type: text/plain` · ตอบ `{ ok: true, data }` หรือ `{ ok: false, code, error }`

| action | ใคร | ทำอะไร |
|---|---|---|
| `config` | ทุกคน (ไม่ต้องมี token) | รอบปัจจุบัน |
| `records` `{token, classroomId}` | ครูประจำชั้นห้องนั้น / ADMIN | ค่าที่บันทึกไว้ของห้องในรอบปัจจุบัน |
| `save` `{token, classroomId, rows}` | ครูประจำชั้นห้องนั้น / ADMIN | upsert ตาม (`round`, `studentId`) ภายใต้ `LockService` |
| `summary` `{token}` | ล็อกอินแล้ว | `studentId` ที่กรอกครบในรอบนี้ (หน้าเว็บนับต่อห้องเอง) |

## 🔴 กับดัก 10 ข้อ

1. **ต้องเพิ่มโดเมนของหน้าเว็บใน `CORS_ORIGINS` ของ API แล้ว redeploy** — GitHub Pages คือ
   `https://<user>.github.io` (ไม่มี path) · ไม่เพิ่ม = ล็อกอินไม่ได้ ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้"
   · เปิด `index.html` จากไฟล์ในเครื่องกับ API production **ไม่ได้** (production ไม่รับ localhost/null)
2. **CORS ของ Apps Script** — ต้อง `POST` แบบ `text/plain` ห้ามมี header เพิ่ม (ไม่งั้นมี preflight
   ซึ่ง Apps Script ตอบไม่ได้) → token จึงส่งใน body ไม่ใช่ header `Authorization`
3. **แก้ `code.gs` แล้วต้องออกเวอร์ชันใหม่** — Deploy ▸ Manage deployments ▸ ✏️ ▸ Version: *New version*
   (กด New deployment = ได้ URL ใหม่ ต้องแก้ `config.js`)
4. **Web App ต้องเป็น Execute as: Me · Who has access: Anyone** — ไม่งั้นได้หน้าล็อกอิน Google แทน JSON
5. **token ของระบบเดิมอายุ 7 วัน และใช้ได้ทุกอย่างที่บัญชีนั้นทำได้** — ห้าม log token ใน Apps Script
   · cache ใช้ hash ของ token เป็น key ไม่ใช่ token ดิบ
6. **API ให้หน้าละไม่เกิน 200 รายการ** — ต้องวนหน้าจนครบ (`meta.totalPages`)
7. **GET ทุกเส้นที่ใช้ TEACHER อ่านได้** (ด่านกลางบังคับ ADMIN เฉพาะการเขียน) — แต่ห้ามใช้
   `?fullCitizenId=true` (403) และไม่ต้องใช้เลย
8. **บันทึกพร้อมกันสองเครื่อง** — `save` ต้องครอบด้วย `LockService` ไม่งั้นแถวซ้ำ
9. **นักเรียนย้ายออกกลางรอบ** — แถวใน `Records` ยังอยู่ แต่หน้าติดตามนับเทียบกับรายชื่อ `STUDYING`
   ตอนนี้ จึงไม่เกิน 100%
10. **ตารางกรมอนามัยไม่มีเด็กหญิงสูงเกิน 175 ซม. / ชายเกิน 185 ซม. / เตี้ยกว่า 90 ซม.** — แสดง "นอกตาราง"
    ไม่เดาค่า
